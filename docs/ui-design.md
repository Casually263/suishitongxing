# 用户端现代国风设计与实现

2026-10-28。沿用现有 Vue 3 / TypeScript / Vue Router / Pinia / vue-i18n 与真实后端，未重建工程，未新增 npm 依赖。此次只修改用户端呈现与客户端接口封装，没有修改数据库迁移或服务端业务协议。

## 视觉规范

宣纸底色 `#f7f4ec`，正文墨黑 `#2c312b`。主标题用设备已有宋体/Georgia，交互与说明用系统黑体，不下载字体。页面以细线、留白、低对比纸纹、小圆角和原创山水矢量组织层次；没有 Emoji 图标、外链图片或商业插画。

| 主题 | 主色 | 代表篇章 | 页面应用 |
| --- | --- | --- | --- |
| 春生 | `#356855` 青绿 | 立春 | 首页、立春阅读器、同行空间 |
| 夏长 | `#a44c3c` 朱红 | 夏至 | 首页可切换主题 |
| 秋收 | `#92651e` 琥珀金 | 立秋 | 首页主题、文化手记 |
| 冬藏 | `#455775` 靛蓝 | 冬至 | 首页主题、数字岁时册 |

令牌位于 `web/src/styles/experience.css`，以 `data-season` 定义局部颜色，管理端保留原有样式。`SeasonArtwork.vue` 用同一套山、水、村落与植物路径绘制四季变体；夏季含荷花、秋季落叶、冬季积雪。SVG 与纸纹均由项目代码原创绘制，来源见 [素材台账](content/assets.md)。

## 页面与实际数据

| 入口 | 已实现体验 | 数据来源与边界 |
| --- | --- | --- |
| `/` | 24节气环形导览、方向键/下拉选择、四季主题、已开放篇章、继续故事、个人进度入口 | `/chapters` 决定开放状态、简介、存档状态；`/profile` 计算档案完整度；`/stories/rewards` 计算印章数量 |
| `/stories/1` | 插画阅读器、字号切换、中英对照、知识出处、六类交互、存档行囊、小满SSE对话 | 原有 state/cards/start/join/choose 与 AI 接口；节点、线索、选项、反馈、分数全由后端提供 |
| `/collaboration` | 立春双笺空间、本人/同行者视角、邀请、独立线索、提交/等待/截止/超时操作 | `/stories/1/state` 和原有 `/choose`；与阅读器共用 `DualInteraction.vue`，每4秒轮询正在进行的真人 dual 节点 |
| `/gifts` | 回礼/打卡筛选、原文中英对照、缺少语言提示、未开始空状态 | 遍历已发布篇章的本人 state.submissions；只展示本人内容，没有虚构对方回礼，也没有自动翻译 |
| `/passport` | 藏蓝收藏册、24格印章墙、获得年份筛选、结局/日期详情、打印样式 | `/stories/rewards`；每一枚已获印章均对应服务端完成记录，页面加载或失败时不渲染伪造的0印章 |

24个节气名称是静态分类词表，**不是年度日期种子**。当前后端没有年度节气日期接口，页面明确标为文化导览，不显示“当前节气”、倒计时或推算日期。未来接入日期API时以数据库为准。

四季按钮分别跳到立春、夏至、立秋、冬至。尚未发布的章节只呈现筹备说明，可回到实际开放的立春篇章，不创建假的游戏入口。首页档案完整度沿用原来的五项等权规则，不代表配对成功率或文化能力评分。

岁时册按奖励 `awardedAt` 的获得年份筛选，提供全部年份视图；不把自然年收藏当作应时完成。回礼在桌面并排、窄屏按中英顺序排列。打印调用浏览器真实打印功能，隐藏导航和操作按钮，不声称已经完成分享海报生成。

## 交互、安全和响应式

- 保留两个身份域的登录/刷新/退出、内存JWT与路由守卫；新增页面也必须登录。
- 保留服务端版本号、请求UUID和重复提交保护。阅读器显示正在保存/保存完成，接口失败可重试；网络不确定时重用原提交UUID。正确答案、分支条件与奖励仍由服务端负责。
- 同行空间不请求另一用户的 state，不渲染另一人的答案；第一人提交后持久化等待，刷新或回到阅读器后可继续。
- 小满的模型/脚本身份、来源提示、对话记录、发送与中断操作保留。UI不能通过聊天发放印章。
- 加载指示、数据缺失、请求失败/重试与空收藏分别呈现。知识卡读取失败单独提示并支持重试，不再被存档刷新清除。
- 节气按钮提供双语 accessible name、`aria-pressed`、方向键/Home/End导航和原生下拉替代；表单有标签，错误使用 alert、提交状态使用 status，提供跳至正文入口。
- 使用 1100 / 900 / 640px 断点；阅读器、双笺、印章墙和中英手记各自适配。已检查 360、390、768、1280、1440px 代表宽度。
- 微动效限于按钮/主题的短过渡、卡片轻微抬升和加载环；尊重 `prefers-reduced-motion`。无自动轮播与装饰性持续晃动。
